# GitHub-Profil

Das Profil liegt unter [github.com/Sinan787](https://github.com/Sinan787). Die Dateien werden im Repository [Sinan787/Sinan787](https://github.com/Sinan787/Sinan787) auf `main` gepflegt.

## Dateien

- `README.md`: englische Profiltexte, Fokusbereiche und Lernziele.
- `assets/neural-banner.svg`: dunkler Hero mit neuronalem Globus, Orbitalbahnen und animierten Signalen.
- `assets/learning-loop.svg`: geplanter Ablauf des AI-Lernbegleiters mit Feedback-Schleife.

Beide Grafiken sind eigenständige SVGs ohne externe Fonts, Bilddienste oder Skripte. Die Animationen berücksichtigen `prefers-reduced-motion`; das vollständige Motiv bleibt auch ohne Animation sichtbar. Die Darstellung kann je nach Viewer variieren. Die Bildbeschreibungen stehen zusätzlich als Alt-Texte in der README.

## Aktualisieren

Profiltexte und Grafiken bearbeiten, Änderungen prüfen und pushen:

```sh
git add README.md SETUP-DE.md assets/
git commit -m "Update AI profile"
git push
```

Die Projektbeschreibung benennt eine Entwicklungsrichtung. Tools und Interessen sind bewusst als Erfahrungen und Lernfelder formuliert. Fertige Projekte können später mit ihren tatsächlichen Repository-Links ergänzt werden.
